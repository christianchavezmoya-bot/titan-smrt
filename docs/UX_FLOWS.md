# Titan UX Flows

## 3-Click Rule

- Start workout: Hub -> Smart Start -> Finish Set -> End Session.
- Log a set: Hub -> Exercise card -> Finish Set.
- View AI insight: Analytics -> Insight card.
- Upgrade: Profile -> Subscription -> Start Trial.

## Tabs

1) Hub: active workout or ready state.
2) Analytics: heatmaps + AI insights.
3) Exercises/Routines: library + templates.
4) Profile: settings + subscription + social feed.

## Critical States

- Offline: app remains fully functional for logging; sync status visible.
- In-workout: minimal navigation, large targets, haptic feedback.
- Pro-gated: explain value; 7-day trial CTA in 1 tap.
